# 🤖 Nova AI — Text & Speech Analysis Chatbot

Nova AI is a Python-based chatbot designed for text and speech interaction with built-in text analysis capabilities.

The project demonstrates how a chatbot can be created from scratch using Python without relying on commercial AI or chatbot APIs.

## 🚀 Features

- 💬 Rule-based chatbot
- 🎤 Speech-to-text input
- 🔊 Text-to-speech output
- 😊 Sentiment analysis
- 🧠 Emotion detection
- 📊 Word statistics
- 🔤 Common-word analysis
- 🎨 Streamlit web interface
- 🔐 No API key required for the chatbot
- 🐍 Built completely with Python

## 🛠️ Technologies Used

- Python
- Streamlit
- SpeechRecognition
- PyAudio
- pyttsx3
- Regular Expressions
- Rule-based Natural Language Processing

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Text-Speech-Chatbot.git
```

Move into the project directory:

```bash
cd Text-Speech-Chatbot
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Run:

```bash
streamlit run app.py
```

The application will open in your browser.

## 🧠 How It Works

The chatbot uses a rule-based Natural Language Processing approach.

1. The user enters text or provides speech.
2. Speech is converted into text.
3. The chatbot preprocesses the input.
4. Keywords and patterns are identified.
5. A suitable response is selected.
6. The input is analyzed for sentiment and emotion.
7. The response can be converted back into speech.

## 📊 Text Analysis

The application analyzes:

- Total number of words
- Number of unique words
- Positive words
- Negative words
- Overall sentiment
- Detected emotion
- Common words
